The **Admissions** page lists every student admission in your institution. From here you can start a new admission, edit an existing one, import students in bulk, and pay pending application processing fees.

To open it, go to **Student Management** > **Admissions**.

## Admissions list

The top of the page shows two summary cards:

- **Total Admissions**: the number of admissions in your institution.
- **Filtered Admissions**: the number of admissions that match your current filters.

The table shows these columns:

| Column | Description |
|--------|-------------|
| **Student Name** | The student's photo, name, and admission number. |
| **Father Name** | The student's father's name. Hidden by default. |
| **Date of Birth** | The student's date of birth. Hidden by default. |
| **Program** | The program the student is enrolled in. |
| **Class** | The class within the program. |
| **Section** | The section the student is assigned to. |
| **Status** | The admission status. |
| **Phone** | The student's mobile number. Hidden by default. |
| **Actions** | The edit (pencil) icon. |

To choose which columns appear, click the **Show/Hide Columns** icon above the table. More records load automatically as you scroll down.

### Admission statuses

The **Status** column shows one of these labels:

- **Under process**
- **Enrolled**
- **Confirmed**
- **Dropout**

### Filter admissions

<Steps>
  <Step title="Open the filters">
    Click the filter icon in the table header. The **Filters** panel opens on the side.
  </Step>
  <Step title="Set your filters">
    Use any combination of these fields:

    - **Search**
    - **Program**
    - **Section**
    - **Referred by**
    - **Status**: choose **Active** or **Dropouts**.
  </Step>
  <Step title="Apply the filters">
    Click **Search** to apply the filters. Click **Reset** to clear them.
  </Step>
</Steps>

## Add or edit an admission

- To start a new admission, click **New Admission**. The admission form opens.
- To edit an existing admission, click the pencil icon in the **Actions** column of that row.

For details on each tab of the form, see [Admission form](/students/admission-form).

## Drop a student

<Steps>
  <Step title="Open the admission details">
    Click the student's name in the **Student Name** column. The **Admission details** window opens.
  </Step>
  <Step title="Drop the student">
    Click **Drop student**. The window closes after the student is dropped.
  </Step>
</Steps>

<Warning>
  The student is dropped as soon as you click **Drop student**. No confirmation prompt appears.
</Warning>

To see dropped students later, filter the list with **Status** set to **Dropouts**.

## Pay pending processing fees

If one or more admissions still have an unpaid application processing fee, a **Pay processing fees** button appears in the table header.

1. Click **Pay processing fees**. The label changes to **Generating Payment Link...** while the link is created.
2. Complete the payment on the payment page that opens. This payment covers all admissions with a pending processing fee.
3. After payment, Chaarvy shows **Validating Payment...** and then returns you to the **Admissions** page.

## Bulk upload students

Use **Bulk Upload** to create or update many student admissions and their fees from an Excel file. Click **Bulk Upload** in the table header to open the **Bulk Upload Students & Fees** window.

<Steps>
  <Step title="Download the template">
    Under **Step 1: Download Template**, click **Download Template (.xlsx)**.

    To update existing students, select **Include active records (for update)** before you download. The template then includes your current active records.
  </Step>
  <Step title="Fill in and select the spreadsheet">
    Complete the template. Then, under **Step 2: Select or Drop Completed Spreadsheet**, click the upload area to browse, or drag and drop the file.

    Only `.xlsx` files are accepted. Chaarvy validates the file automatically as soon as you select it.
  </Step>
  <Step title="Review the validation results">
    Under **Step 3: Validation Results**, check the **Total Rows**, **Valid**, and **Errors** counts.

    A fee summary shows **Course Fees**, **Addon Fees**, **Books Fees**, and **Grand Total Payable** for the valid rows. Click **Show Preview of Valid Rows** to see each valid row with its admission number, student name, course fees, add-on courses, and payable amount.

    If any rows have errors, click **Download Error Sheet to Fix** to get a spreadsheet of the rows you need to correct.
  </Step>
  <Step title="Choose an upload mode">
    Under **Upload Mode**, select one option:

    - **Skip errors and import valid rows (Recommended)**: imports the valid rows and skips rows with errors.
    - **All-or-nothing**: rejects the whole upload if any row has an error.

    You can't import in **All-or-nothing** mode while the file has errors.
  </Step>
  <Step title="Import">
    Click **Confirm & Import**. The button shows how many students will be imported. The admissions list refreshes when the import finishes.
  </Step>
</Steps>

<Tip>
  To correct errors, fix the rows in the downloaded error sheet, then select the corrected file again. Chaarvy validates the new file automatically.
</Tip>
