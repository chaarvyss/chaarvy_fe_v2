The admission form captures everything Chaarvy needs to enroll a student. It has five tabs:

1. **Student Base Details**
2. **Student Details**
3. **Student Address**
4. **ADDON Courses**
5. **Fees Details**

## Open the form

Go to **Student Management** > **Admissions**, then do one of the following:

- To create an admission, click **New Admission**.
- To edit an admission, click the pencil icon in the **Actions** column of the student's row.

When you create a new admission, only the **Student Base Details** tab is available at first. The other tabs become available after the student is enrolled and the application processing fee is paid. Each tab is colored to show its status. A green tab indicates a completed section.

## Student base details

This tab creates the admission. Fields marked with an asterisk (*) are required.

| Field | Required | Notes |
|-------|----------|-------|
| Photo | Yes | Click **Upload Photo** to select an image. |
| **Admission number** | Yes | |
| **Student Name** | Yes | Enter the name as per SSC records. |
| **Student PEN number** | No | |
| **Student Aapaar Number** | No | |
| **Program / Group** | Yes | Lists active programs. |
| **Class** | Yes | Lists the classes of the selected program. |
| **Medium** | Yes | Lists the mediums available for the selected class. |
| **Section** | Yes | Lists the sections available for the selected medium. |
| **Gender** | Yes | |
| **Date of Birth** | Yes | |
| **Student Email** | Yes | Must be a valid email address. |
| **Mobile number** | Yes | Must be a valid phone number. |
| **Student Aadhar** | Yes | Must be 12 digits. |
| **Referred by** | No | Select the user who referred the student. This value appears in [Referrals](/students/referrals). |

<Note>
  Select the fields in order. **Class** options depend on **Program / Group**, **Medium** depends on **Class**, and **Section** depends on **Medium**.
</Note>

### Photo requirements

Chaarvy compresses the image you select before saving it. The processed file must be between 50 KB and 500 KB. If it falls outside this range, an error appears and you need to choose a different image. Click the photo preview to view it at a larger size.

### Save the base details

For a new admission, the page shows the **Processing Fees** amount. Click **Enroll and Continue** to create the admission. When you edit an existing admission, the button reads **Save and Continue**.

If any field is missing or invalid, Chaarvy shows the message **Please correct the errors before submitting.** and highlights the fields to fix.

### Application processing fees

If the application processing fee is not yet paid, the **Application Processing Fees** window opens after you click **Enroll and Continue**. It shows the fee amount that will be collected.

- Click **Proceed to Pay** to open the payment page. After the payment, Chaarvy validates it and returns you to the **Student Details** tab of this admission.
- Click **Skip now** to return to the **Admissions** list without paying.

If you skip, you can pay later with the **Pay processing fees** button on the Admissions page. See [Pay pending processing fees](/students/admissions#pay-pending-processing-fees).

## Student details

All fields on this tab are optional.

- **Qualified Exam**
- **Hall ticket number**
- **Year of pass**: choose from the last 10 years.
- **Father Name**
- **Father Occupation**
- **Mother Name**
- **Mother Occupation**
- **Alternative number**: must be a valid mobile number if entered.
- **Father Aadhar** and **Mother Aadhar**: must be valid Aadhar numbers if entered.
- **Religion**
- **Caste / Community**
- **Sub caste**

Click **Save and continue** to save and move to the **Student Address** tab.

## Student address

Enter the student's address. All fields except **Landmark** are required.

- **Door No**
- **House / Apartment**
- **Street**
- **Landmark**
- **Village / City**
- **State**
- **District**
- **Pincode**: must be exactly 6 digits.

Click **Submit** to save the address and move to the **ADDON Courses** tab.

## Add-on courses

The **Enroll Addon courses** table lists the add-on courses available for the student, with these columns:

- **Addon Course**
- **Course fees**
- **Seats available**

To enroll the student, click **Enroll** on a course row. The button is disabled when no seats are available. After enrolling, the row shows an **Enrolled** tag. To remove the enrollment, click the **Enrolled** tag.

If no courses are listed, the table shows **No Addon courses available for this student**.

## Fees details

This tab sets the final fee the student must pay. The page shows four summary cards:

- **Actual fees**: the total standard fee.
- **Payable fees**: the total the student will pay.
- **Discount**: the difference between actual and payable fees.
- **Discount%**: the discount as a percentage of the actual fees.

The tab has three tables:

<AccordionGroup>
  <Accordion title="Course fees">
    Lists each fee particular for the program with its **Actual fees**. Enter the amount the student will pay in the **Final Payable** field. The field is highlighted as an error if the amount is higher than the actual fee.
  </Accordion>
  <Accordion title="Books Fees">
    Lists the books for the program with **Quantity** and **Price**. Use the **Selected** checkbox to include or exclude each book. Only selected books count toward the fees.
  </Accordion>
  <Accordion title="Addon Courses Fees">
    Lists the add-on courses the student is enrolled in. Enter the amount the student will pay in the **Final Payable** field. If no courses are enrolled, the table shows **No Addon courses enrolled**.
  </Accordion>
</AccordionGroup>

When the amounts are correct, click **Finalize**. If the fees were already saved, the button reads **Update Fees details** and is enabled only after you change something. The button is disabled if the total payable fees are higher than the actual fees.

After you finalize the fees, you can collect payments against them. See [Collect payment](/students/payments).
