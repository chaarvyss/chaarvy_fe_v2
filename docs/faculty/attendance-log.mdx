The **Attendance Log** lists recorded attendance sessions. Use it to review past sessions and their attendance percentage. To mark attendance, use the **Attendence Register** instead. See [Attendance](/academics/attendance).

Go to **Faculty Corner** > **Attendence** to open the log.

## Log columns

Each row is one attendance session.

| Column | What it shows |
|---|---|
| **Date** | The date of the session. |
| **Period** | The period of the session. |
| **Program** | The program of the class. |
| **Segment** | The segment of the class. |
| **Medium** | The medium of the class. |
| **Section** | The section of the class. |
| **Status** | **Saved** or **Draft**. |
| **Recorded By** | The user who recorded the attendance. |
| **Attendance %** | A chart showing the attendance percentage for the session. |

## Filter the log

<Steps>
  <Step title="Open the filters">
    Click the filter icon in the table header. The **Filter** panel opens.
  </Step>
  <Step title="Choose your filters">
    Set any combination of these filters:
    - **Program**
    - **Segment**
    - **Section**
    - Date range: select a start and end date.
  </Step>
  <Step title="Apply the filters">
    Click **Search** to update the list. Click **Reset** to clear all filters.
  </Step>
</Steps>

## Open a session

Click any row to open that session in the **Attendence Register**. There you can see the student-level attendance for the session.
