Add-on courses are optional courses that students can enroll in alongside their main program. For each course, you choose which programs, segments, and mediums offer it, and set the seating capacity and fees for each.

Go to **Administration** > **Addon Courses**. The **Add-On Courses** table has these columns:

| Column | Description |
| --- | --- |
| **#** | Row number. |
| **Course Name** | The name of the add-on course. |
| **Status** | **Active** or **Inactive**. |
| **Actions** | Pencil icon to edit the course. |

## Create an add-on course

<Steps>
  <Step title="Open the form">
    Click **Add Add-On Course**. The **Add-On Courses** window opens.
  </Step>
  <Step title="Enter the course name">
    Type a name in **Course Name**. This field is required.
  </Step>
  <Step title="Choose where the course is offered">
    Programs are listed with checkboxes. Click **+** next to a program to show its segments, and **+** next to a segment to show its mediums. Select a program, segment, or medium to include it. Selecting a program or segment selects everything under it.
  </Step>
  <Step title="Enter capacity and fees">
    For each selected medium, enter **Seating capacity** and **Fees**. Both are required and can't be negative. Programs and segments with missing or invalid values are highlighted in red.
  </Step>
  <Step title="Save">
    Click **Save**. The footer shows how many changes and removals you are about to save. **Save** stays disabled until the course has a name, all selected mediums have valid values, and you have made a change.
  </Step>
</Steps>

## Edit an add-on course

<Steps>
  <Step title="Open the course">
    Click the pencil icon in the **Actions** column. The window opens with the current selections, capacities, and fees.
  </Step>
  <Step title="Rename the course (optional)">
    Click the pencil icon next to the course name, type the new name, then click the save icon.
  </Step>
  <Step title="Update the offerings">
    Select or clear mediums, and change **Seating capacity** or **Fees**. Clearing a medium removes the course from that program, segment, and medium.
  </Step>
  <Step title="Save">
    Click **Save**.
  </Step>
</Steps>

## Activate or deactivate a course

Click the **Active** or **Inactive** tag in the **Status** column. The status switches to the other value.

<Tip>
  Students are enrolled in add-on courses on the **ADDON Courses** tab of the admission form. See [Admission form](/students/admission-form).
</Tip>
