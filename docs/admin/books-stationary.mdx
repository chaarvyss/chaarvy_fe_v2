The **Books & Stationary** page holds your catalog of books and stationery items. Each item has a price and a stock count. An item is either common to all programs or linked to specific programs, a segment, and a medium.

Go to **Administration** > **Books & Stationary**.

## The books list

The **Books** table has these columns:

| Column | Description |
| --- | --- |
| **#** | Row number. |
| **Book Name** | The item name. Below it, you see **Common book**, or the linked programs, segment, and medium. |
| **Available qty** | Current stock. |
| **Price** | Unit price. |
| **Actions** | Pencil icon to edit the item. |

### Filter the list

Click the filter icon to open the **Filters** panel. You can filter by **Search**, **Program**, and **Segment**. Click **Search** to apply the filters, or **Reset** to clear them.

## Add or update items

Items are added and edited in the **Update Books and Stationary Details** window.

<Steps>
  <Step title="Open the window">
    Click **Add books**. To edit an existing item, click the pencil icon in its row instead.
  </Step>
  <Step title="Choose the item type">
    Select one option:
    - **Specific**: the items belong to particular programs, a segment, and a medium.
    - **Common**: the items apply to all programs.
  </Step>
  <Step title="Choose where the items belong (Specific only)">
    Select one or more values in **Program**, then a **Segment** and a **Medium**. The table appears after you select all three.
  </Step>
  <Step title="Edit the table">
    The table lists existing items for your selection, with **Book Name**, **Price**, and **Stock** columns.
    - Click **Add New Row** to add an item.
    - Click the pencil icon on a row to change it, then the check icon to finish.
    - Click the delete icon to remove an item from the current selection.
    - Use **Undo**, **Redo**, or **Reset** to correct mistakes.
  </Step>
  <Step title="Submit">
    Click **Submit**. A **Process Summary** window shows counts for **Creating**, **Updating**, **Skipped**, **Failed**, and **Exceptions**.
  </Step>
</Steps>

<Note>
  When you add a new item with several programs selected, Chaarvy links the item to each selected program. When you edit an existing specific item, clearing a program from **Program** removes the item's link to that program.
</Note>

## Bulk upload

Use **Bulk Upload** to add or update many items at once from an Excel (.xlsx) workbook. The window is titled **Bulk Upload Books & Curriculum**.

The workbook has two sheets:

- **Books_Master**: the stock catalog, with Book Name, Medium, Price, and Available Qty. Each book appears once per medium.
- **Book_Mappings**: the curriculum assignments, with Program(s), Segment(s), and Is Common. You can enter several programs separated by commas, or use `All Programs`.

<Steps>
  <Step title="Download the template">
    Under **Step 1: Download Template**, click **Download Template (.xlsx)**. Turn on **Include active records (for update)** to download your current books so you can edit them.
  </Step>
  <Step title="Upload the completed file">
    Under **Step 2: Select or Drop Completed Spreadsheet**, click the area or drag your .xlsx file onto it. Chaarvy validates the file as soon as you select it.
  </Step>
  <Step title="Review the validation results">
    **Step 3: Validation Results** shows **Total Rows**, **Valid**, and **Errors**. If there are errors, the first few are listed. Click **Download Error Sheet to Fix** to get a copy of the file with all errors.
  </Step>
  <Step title="Choose an upload mode">
    Select one option:
    - **Skip errors and import valid rows (Recommended)**: imports only the valid rows.
    - **All-or-nothing**: rejects the whole upload if any row has an error. You can't use this mode while errors remain.
  </Step>
  <Step title="Import">
    Click **Confirm & Import**. The button shows how many valid books will be imported.
  </Step>
</Steps>

<Tip>
  You can also download the books template from **Administration** > **Reports**. See [Reports](/admin/reports).
</Tip>
