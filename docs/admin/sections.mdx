Sections are the class divisions your institution uses, such as *A* or *B*. You create the section names here, then assign them to program segments.

Go to **Administration** > **Sections**. The table lists each section with its number (**S#**), **Section Name**, and an **Action** menu.

## Add a section

<Steps>
  <Step title="Open the form">
    Click **Add Section**. The **Section** window opens.
  </Step>
  <Step title="Enter the name">
    Type a name in **Section Name**. Each name must be unique. If the name already exists, you see **Section name already exists**.
  </Step>
  <Step title="Save">
    Click **Submit**. The button is disabled until you enter a name.
  </Step>
</Steps>

## Rename a section

<Steps>
  <Step title="Open the menu">
    Click the menu icon in the **Action** column and choose **Edit**.
  </Step>
  <Step title="Change the name">
    Update **Section Name**.
  </Step>
  <Step title="Save">
    Click **Submit**.
  </Step>
</Steps>

## Assign sections to programs

To set which sections a program segment uses and their capacity, open the program on the [Programs](/academics/programs) page and use its **Sections (capacity)** tab.
