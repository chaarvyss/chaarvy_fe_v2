Fee types are the categories your institution uses to classify charges — such as tuition fees, exam fees, or lab fees. Before you can configure fees for any academic program, you need to set up the relevant fee types here. Think of fee types as the building blocks that your program fee structures are assembled from.

## Creating a Fee Type

Navigate to **Admin → Fee Types** to manage your institution's fee categories.

<Steps>
  <Step title="Add a new row">
    In the Fee Types table, click the **Add** button to insert a new row.
  </Step>
  <Step title="Enter the fee type name">
    Type a clear, descriptive name for the fee category directly in the row. Common examples include:
    - Tuition Fee
    - Exam Fee
    - Lab Fee
    - Library Fee
    - Sports Fee

    Choose names that will be recognisable to the staff who configure program fees later.
  </Step>
  <Step title="Save your changes">
    Click **Save** to submit all pending additions and edits. A confirmation summary will indicate which entries were processed successfully.
  </Step>
</Steps>

## Managing Fee Types

Once fee types are created, you can rename or remove them directly from the same table.

<Steps>
  <Step title="Rename a fee type">
    Click on any fee type name in the table to edit it inline. Update the name and click **Save** to apply the change. The update is reflected immediately wherever the fee type is already in use.
  </Step>
  <Step title="Delete a fee type">
    Select the delete option next to a fee type to mark it for removal, then click **Save** to confirm. Fee types that are already linked to program fee configurations should be removed with care, as this may affect existing fee structures.
  </Step>
</Steps>

<Tip>
  Fee types you create here are used when building out fee structures for your academic programs. Head to the [Programs](/academics/programs) section to see how fee types map to per-program charges that appear on student fee invoices.
</Tip>
