Programs are the foundation of your academic structure in Chaarvy. Subjects, timetables, fees, books, and attendance all depend on how you set up each program.

In the app, programs live under the **Administration** menu. Go to **Administration** > **Programs** to open the programs list.

## How a program is structured

Each program is built from four building blocks:

| Building block | What it represents | Where it comes from |
| --- | --- | --- |
| Segment | A stage of the program, such as a year or semester | You select segments when you create the program |
| Medium | A language of instruction | You enable mediums per segment on the **Mediums** tab |
| Section | A class group within a segment and medium | Sections are defined under **Administration** > **Sections**. See [Sections](/admin/sections). You set capacity per program on the **Sections (capacity)** tab |
| Seating capacity | The number of seats in a section | You enter it on the **Sections (capacity)** tab |

A specific class is a combination of program, segment, medium, and section. The timetable and the attendance register both work at this level.

## The programs list

The programs table shows these columns:

- **#**
- **Program Name**
- **Status**: shows **Active** or **Inactive**. Click the status tag to switch it.
- **Actions**: a menu with **View**, **Edit**, **Books Details**, and **Fees details**.

<Note>
  The timetable and the attendance register only list active programs.
</Note>

## Create a program

<Steps>
  <Step title="Open the Create Program dialog">
    Go to **Administration** > **Programs** and click **Create Program**.
  </Step>
  <Step title="Enter the program name">
    Type the name in the **Program name** field. For example, *B.Sc. Computer Science*.
  </Step>
  <Step title="Select segments">
    Select the checkbox for each segment this program uses. You must select at least one segment.
  </Step>
  <Step title="Save">
    Click **Create Program**. The button stays disabled until you enter a name and select at least one segment.
  </Step>
</Steps>

To rename a program, open its **Actions** menu and click **Edit**. The **Edit Program** dialog shows only the **Program name** field. You can't change segments from this dialog.

## Configure segments, mediums, and sections

Open a program's **Actions** menu and click **View**. A dialog titled with the program name opens with three tabs.

All three tabs use the same editable table:

- Edited rows are highlighted as **New Rows** or **Updated Rows**.
- Use the undo and redo icons to step through your changes.
- Click **Reset** to discard changes, or **Submit** to save them.
- When a tab has no saved data yet, click **Set Default data** to prefill a row for each segment.

<Tabs>
  <Tab title="Segments">
    Lists each segment selected for the program. Use the **Status** checkbox to turn a segment on or off for this program, then click **Submit**.
  </Tab>
  <Tab title="Mediums">
    Shows one row per segment and one checkbox column per language. Select the languages taught in each segment, then click **Submit**.
  </Tab>
  <Tab title="Sections (capacity)">
    Select a medium using the buttons at the top right. The table shows one row per segment and one column per section. Enter the seating capacity for each section, then click **Submit**. Use **Add New Row** to add a segment that isn't listed yet.
  </Tab>
</Tabs>

<Warning>
  A section only appears in the timetable when its seating capacity is greater than 0. A medium only appears in the timetable when it has at least one such section in that segment.
</Warning>

## Assign books to a program

Use **Books Details** to set which books and stationery items students in a class need, and in what quantity.

<Steps>
  <Step title="Open Program Books">
    Open the program's **Actions** menu and click **Books Details**. The **Program Books** dialog opens.
  </Step>
  <Step title="Choose the class">
    Select the **Program**, **Segment**, and **Medium**. The table loads the books already assigned to that combination.
  </Step>
  <Step title="Add or edit books">
    Click **Add New Row**, then choose a **Book** and enter a **Quantity**. If no books are assigned yet, click **Set Default data** to add every available book with a quantity of 1.
  </Step>
  <Step title="Save">
    Click **Submit**. A status dialog shows how many rows were created, updated, skipped, or failed.
  </Step>
</Steps>

The **Book** list comes from the items you manage in [Books & Stationary](/admin/books-stationary).

## Set program fees

Use **Fees details** to enter the fee amount for each fee type in every class of the program.

<Steps>
  <Step title="Open the fees editor">
    Open the program's **Actions** menu and click **Fees details**. The **Program Fees Details** grid opens.
  </Step>
  <Step title="Review the grid layout">
    Each row is an active fee type. Columns are grouped by medium, then segment, then section. A **TOTAL** row at the bottom adds up each column.
  </Step>
  <Step title="Enter amounts">
    Click a cell and type the amount. Changed cells are highlighted until you save.
  </Step>
  <Step title="Save">
    Click **Save**. The button is disabled until you change at least one cell.
  </Step>
</Steps>

<Tip>
  To reuse amounts, click a medium, segment, or section name in the grid header. Choose the target mediums, segments, or sections, then click **Copy**. The amounts are copied into the matching cells. Click **Save** to keep them.
</Tip>

Fee types come from [Fees types](/admin/fees-types). Only active fee types appear as rows.
