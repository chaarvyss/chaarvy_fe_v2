Academic programs are the foundation of your institution's structure in Chaarvy. Every subject assignment, timetable, and attendance record ultimately belongs to a program, so setting them up accurately ensures the rest of your academic operations run smoothly.

## Creating a Program

To add a new program to your institution, follow these steps:

<Steps>
  <Step title="Open the Programs module">
    From the Admin sidebar, navigate to **Programs**. The page lists all existing programs along with their current status.
  </Step>
  <Step title="Click Add Program">
    Select the **Add Program** button in the top-right corner to open the program creation form.
  </Step>
  <Step title="Enter the program name">
    Type a clear, recognisable name for the program (for example, *B.Sc. Computer Science* or *Diploma in Nursing*). This name appears throughout Chaarvy wherever the program is referenced.
  </Step>
  <Step title="Set the program status">
    Choose **Active** to make the program immediately available for timetables, enrollments, and attendance. Select **Inactive** if you are setting the program up in advance and it is not yet ready for use.
  </Step>
  <Step title="Save the program">
    Click **Save**. The new program appears in the programs list and is ready for further configuration.
  </Step>
</Steps>

## Program Structure

Once a program exists, you define its internal structure using three building blocks: **segments**, **mediums**, and **sections**. Together, these three dimensions describe exactly which class a student belongs to.

### Segments

A segment represents a time-based division of the program — typically an academic year or a semester. For example, a three-year degree program might have segments named *Year 1*, *Year 2*, and *Year 3*, while a semester-based program might use *Semester 1* through *Semester 6*. Subjects, timetables, and fee structures are all configured at the segment level, so define your segments before moving on.

### Mediums

A medium is the language of instruction used for a particular group of students within the same program and segment. Common examples include *English* and *Tamil*. If your institution offers the same program in more than one language, create a medium for each. If only one language is used, a single medium is sufficient.

### Sections

Sections divide students within a segment-and-medium combination into smaller class groups, typically identified by letters such as *Section A* or *Section B*. Sections are the most granular unit: a timetable is built for a specific program → segment → medium → section combination, and attendance is taken at the section level.

## Program Books

You can attach a list of required textbooks and reference materials directly to a program so that faculty and administrators have a single source of truth for course materials.

<Steps>
  <Step title="Open the program">
    On the Programs list, click the program you want to update to open its detail view.
  </Step>
  <Step title="Go to the Books tab">
    Select the **Books** tab within the program detail page.
  </Step>
  <Step title="Add a book">
    Click **Add Book**, enter the book title, author, and any other relevant details, then save. Repeat for each required title.
  </Step>
</Steps>

## Program Fees

Chaarvy lets you configure a fee structure for each program and segment combination, ensuring that billing accurately reflects a student's current stage in the program.

<Steps>
  <Step title="Open the Fees tab">
    Inside the program detail view, select the **Fees** tab.
  </Step>
  <Step title="Select a segment">
    Choose the segment (year or semester) for which you are defining fees.
  </Step>
  <Step title="Add fee components">
    Click **Add Fee** and enter the fee component name (for example, *Tuition Fee*, *Library Fee*, or *Exam Fee*) along with the amount. Add as many components as needed.
  </Step>
  <Step title="Save the fee structure">
    Click **Save** to apply the fee structure to that segment. Repeat the process for each segment in the program.
  </Step>
</Steps>

## Add-On Courses

Add-on courses are optional or supplementary courses that students in a program can enroll in alongside their core curriculum. Linking them to a program keeps the catalog organised and makes enrollment management straightforward.

<Steps>
  <Step title="Open the Add-On Courses tab">
    Inside the program detail view, select the **Add-On Courses** tab.
  </Step>
  <Step title="Link a course">
    Click **Add Course**, search for the add-on course by name, and select it from the results.
  </Step>
  <Step title="Save">
    Confirm the selection. The linked course now appears under the program and is available for student enrollment.
  </Step>
</Steps>

<Tip>
  You can deactivate a program at any time by changing its status to **Inactive**. Inactive programs are hidden from new timetable creation and enrollment flows but all historical data — attendance records, grades, and fees — is preserved. Reactivate the program whenever you are ready to resume operations.
</Tip>
