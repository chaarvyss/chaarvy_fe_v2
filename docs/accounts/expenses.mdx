The **Expenses** page is where you record money your institution pays out. Each expense stores who paid, who received the payment, the category, the payment mode, and any receipts or invoices you attach.

Go to **Accounts** > **Expenses** to open it.

## Expense list

The **Total Expenses** card at the top of the page shows the total expense amount.

The list shows these columns:

| Column | What it shows |
|---|---|
| **S#** | The row number. |
| **Payment date** | The date of the expense. |
| **Expense category** | The category of the expense. |
| **Beneficiary name** | The payee who received the payment. |
| **Beneficiary type** | The type of payee. |
| **Amount** | The amount paid. |
| **Payment mode** | How the payment was made. |
| **Actions** | The edit (pencil) icon. Shown only if you have permission to edit expenses. |

## Filter expenses

<Steps>
  <Step title="Open the filters">
    Click the filter icon in the table header. The **Filters** panel opens.
  </Step>
  <Step title="Choose your filters">
    Set any combination of these filters:
    - Date range: select a start and end date.
    - **Beneficiary type**: select one or more types.
    - **Payment mode**: select one or more modes.
    - **Expense category**: select one or more categories.
  </Step>
  <Step title="Apply the filters">
    Click **Search** to update the list. Click **Reset** to clear all filters.
  </Step>
</Steps>

## Add an expense

<Steps>
  <Step title="Open the form">
    Click **Add expense**. The **Add expense** panel opens.
  </Step>
  <Step title="Fill in the expense details">
    Complete all of the following fields. Each one is required.

    | Field | Details |
    |---|---|
    | **Description** | A short summary of what the expense is for. |
    | **Date** | The date of the expense. You can pick a date up to 5 years in the past or 1 year in the future. |
    | **Paid by** | The user who made the payment. Type to search users. |
    | **Benficery type** | The type of payee. |
    | **Payee** | The person or party who received the payment. Available after you select a beneficiary type. Type to search. |
    | **Expense Category** | The category of the expense. You can add a new category here. |
    | **Reference id** | A reference for the payment, such as a transaction or cheque number. |
    | **Notes** | Any additional details. |
    | **Payment mode** | How the payment was made. You can add a new payment mode here. |
    | **Amount** | The amount paid. |
  </Step>
  <Step title="Attach files (optional)">
    In the **Attachments** section, click **Select Files** and choose one or more files. You can attach images and PDFs. To remove a file before saving, click the close icon next to it.
  </Step>
  <Step title="Save">
    Click **Add expense**. If you attached files, a progress bar shows the upload for each file. A confirmation message appears when the expense is saved.
  </Step>
</Steps>

### Add or rename categories and payment modes

You can manage expense categories and payment modes directly from the expense form.

- **Add a new entry**: In **Expense Category** or **Payment mode**, type the new name. Then select **Add expense category** or **Add new payment mode** from the list.
- **Rename an entry**: Use the edit option next to an existing entry in the dropdown.

New and renamed entries are available for all future expenses.

## Edit an expense

1. Click the edit (pencil) icon in the expense's row. The **Update expense** panel opens with the current details and attachments filled in.
2. Change the details you need.
3. Manage attachments:
   - Click a file name to view it. PDFs open in a new tab. Images open in a viewer.
   - Click the close icon next to a file to remove it.
   - Click **Select Files** to add more files.
4. Click **Update expense**.

<Note>
  Removed attachments are deleted only when you click **Update expense**.
</Note>

## Permissions

What you can do on this page depends on your role:

- **View list**: required to open the **Expenses** page.
- **Add**: shows the **Add expense** button.
- **Edit**: shows the **Actions** column with the edit icon.

To change these permissions, see [Users and roles](/admin/users-roles).
